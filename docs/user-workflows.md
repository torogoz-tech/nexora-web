# User workflows

The most important web journeys connect engineering work with technical context.

## Repository understanding

1. Open a project and repository.
2. Select an available analysis profile.
3. Inspect the current or historical snapshot.
4. Navigate symbols, dependencies, source context, diagnostics, and coverage.
5. Keep the snapshot identity when comparing or discussing results.

## Governed change

1. Create or open a task.
2. Review acceptance criteria and linked context.
3. Inspect the repository evidence relevant to the change.
4. Review policy findings and unresolved information.
5. Request approval when the workflow requires it.
6. Preserve the decision and evidence in the task, document, or release context.

The exact available action depends on server-side authorization and workflow configuration. The browser never grants itself permission because a button is visible.
