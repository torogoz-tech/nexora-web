# Changelog

## 0.3.2

- Improved the service request detail with section navigation and explicit metadata editing.
- Excluded archived projects from approval request lookup to prevent unavailable-resource errors.

## 0.3.1

- Made the service-request workspace use the full available width.
- Allowed images pasted into new request descriptions to be uploaded with the request attachments.

## 0.3.0

- Added member incorporation requests for OIDC identities and invitations.
- Added approved-member navigation and role visibility.
- Moved Passkey authentication out of primary login into the second-factor gate.
- Added TOTP/Passkey selection with the configured skip limit.

## 0.2.0

- Prepared the web client for the versioned container release.
- Moved member actions to the member profile and hid unavailable navigation and repository sections according to permissions.
- Displayed member positions, consolidated work-hour summaries, and included calendar activity markers.
- Improved commit-binding feedback and allowed transversal commit linking.
- Removed the edit reason from shared task-type forms and kept task purposes immutable during edits.
- Improved the personal MCP key table layout.

## 0.1.0

- Initial open-source publication of the Nexora web client.
